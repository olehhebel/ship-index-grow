# Open-source attribution

This browser setup reuses patterns and compatible components from the following open-source projects:

- Microsoft Playwright MCP
  - Repository: https://github.com/microsoft/playwright-mcp
  - License: Apache License 2.0

- xtr-dev/mcp-playwright-novnc
  - Repository: https://github.com/xtr-dev/mcp-playwright-novnc
  - License: MIT

- noVNC
  - Repository: https://github.com/novnc/noVNC

- x11vnc / Xvfb / Fluxbox
  - Installed from Ubuntu packages.

No account credentials, browser cookies, session data, passkeys or VNC passwords belong in this repository.
